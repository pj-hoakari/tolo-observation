# 観測コンテキスト

## 責務

- 自テナントの計測値を収集・永続化
- 誘導サービス（Flow Control／Line Control）を呼び出すオーケストレータ
- エッジ端末の管理（登録・登録解除・稼働の把握）
- WebRTC シグナリングの仲介（エッジブリッジ）を内包
- ゲスト向け状況の生成と publish（ID と数値のみ。表示名の付与・文言化はゲストが担う）
- 誘導への介入（手動介入・ゲート開閉・観測点設定変更）のシステム接点として直接受け、次回の誘導計算へ反映
- QR 由来計測の計上（トークンなしの発行 URL・設置箇所単位）

## ドメインモデル

| 語 | 英語 | 内容 |
|---|---|---|
| 観測点 | Observation Point | 計測対象（ポイント／ルート）ごとの計測単位<br>計測方式はカメラまたは QR<br>カメラ方式は1エッジ端末に属す（エッジ端末 ∋ 観測点。1台が複数観測点を担いうる）<br>QR 方式は QR 設置箇所に対応しエッジ端末に属さない<br>グラフ要素との関連はグラフ編集が保持 |
| エッジ端末 | Edge Device | Webカメラ＋PC等<br>人検知・人数カウントをエッジで完結<br>登録は実質的に観測点登録を兼ねる<br>観測機能停止時はエッジ端末だが観測点でない状態もありうる |
| 計測値 | Measurement | 観測点からの生データ<br>観測スコアの供給源 |
| 人数カウント | People Counting | 検知・追跡による計上 |
| エッジブリッジ | Edge Bridge | WebRTC シグナリングの仲介<br>映像は仲介せずページ間で直接やりとりする<br>接続の確立後は関与しない |
| 観測ページ URL | Observation Page URL | エッジ端末ごとに発行される固定 URL<br>現場の端末はこの URL を開いて計測値を送る<br>端末の識別子を含み、資格情報ではない（送信には認証を要する） |

## ドメインイベント

| イベント | 英語 | 契機 |
|---|---|---|
| エッジ端末が登録された | EdgeDeviceRegistered | プロビジョニング・登録 |
| エッジ端末が起動した | EdgeDeviceStarted | 稼働開始 |
| エッジ端末が切断した | EdgeDeviceDisconnected | 稼働停止 |
| エッジ端末が登録解除された | EdgeDeviceUnregistered | 撤去した端末を運用から外す |
| 計測値受信された | MeasurementReceived | エッジから到着 |
| 観測スナップショット確定された | SnapshotTaken | 観測ウィンドウ確定 |
| 観測点が登録された | ObservationPointRegistered | 新規登録 |
| 観測点が観測不能化された | ObservationPointDisabled | 欠損が一定時間超過 |
| 観測点が観測再開された | ObservationPointReEnabled | 欠損解消 |
| 観測点設定変更された | ObservationPointReconfigured | スタッフ操作通知 |
| 最適化要求された | OptimizationRequested | スナップショット更新等 |
| 最適化結果永続化された | OptimizationResultPersisted | 最適化応答受信 |
| アクセス要求イベント発生した | AccessRequested | 観測点起動時にオーナー／スタッフが管理 UI から WebRTC でグラフ紐づけ |

## 不変条件

- 自テナントの計測値のみ収集・永続化（クロステナント集約は担わない）
- 計測値は正準単位（人/分）に正規化して渡す
- 観測点はグラフのポイントと1対1ではない
- 観測点とグラフ要素の関連はグラフ編集が保持
- カメラ方式の観測点は1つのエッジ端末に属する（エッジ端末 ∋ 観測点）。QR 方式の観測点はエッジ端末に属さない
- 1つのエッジ端末は0個以上の観測点を担う
- エッジ端末の登録は実質的にカメラ方式の観測点の登録を兼ねる。QR 方式の観測点は QR 設置箇所の登録に対応する（正本はグラフ編集）
- 一つのグラフ要素に紐づく観測点は計測方式を揃える（併存させない）。同一の来場者を二重に数えないため
- 観測スコアは計測方式に応じた悉皆性を伴う。QR 方式は悉皆でなく、絶対量として比較できない
- 観測不能化はカメラ方式のみを対象とする（QR 方式は稼働の途絶を判定できない）
- 観測機能の停止でエッジ端末だが観測点でない状態もありうる
- エッジ端末の切断・登録解除は配下観測点の観測不能化に波及
- 切断は一時的で復帰しうる。登録解除は恒久的で取り消せない
- 登録解除はソフト削除でエッジ端末と観測点の識別子を保持する（グラフ編集が持つ紐づけの宙づりを生まない）
