# 共有カーネル

観測が生成し、Flow Control と Line Control が消費する共同所有モデル。
グラフ構造の正本はグラフ編集が持つ。

## グラフ

| 語 | 英語 | 内容 |
|---|---|---|
| グラフ | Graph | 現場の接続関係をポイントとルートで表すグラフ<br>構造の正本はグラフ編集 |
| ポイント | Point（同義 Node） | 停滞箇所または分岐合流の結節点 |
| ルート | Route（同義 Edge） | ポイント間の通路<br>始点と終点を持ち、方向属性（一方通行／両通行）で通行の向きを表す<br>流量スコア・停滞量スコア・容量ヒントを持つ |
| 入退出点 | Boundary Point | 外部との出入り口になるポイント（`boundary`）<br>向き（入場／退場／入退場）と有効無効を持つ<br>一部は入場ゲートを兼ねる |
| 配置位置 | Graph Anchor | 配置系（観測点紐づけ・QR設置箇所・スタッフ配置）の共有語彙<br>同一要素への複数配置可<br>ルート途中は比率（表示用途のみ。最適化・スコアに不使用） |

- ポイント種別：GOAL（目標）／GOAL_TRANSIT_MIXED（通過目標混在）／TRANSIT_ONLY（通過専用）
- モード：Open（有効な入退出点あり）／Closed（なし）

## 観測スコア

| 語 | 英語 | 内容 |
|---|---|---|
| 人数スコア | People Score | ポイントの占有レベル（人） |
| 占有量変化 | ΔOcc | 観測ウィンドウ内の占有増減（人/分） |
| 流量スコア | Flow Score | ルートの流量（方向別／スカラー。人/分） |
| 停滞量スコア | Stagnation Score | 全体−流量（人）<br>高停滞の主情報源 |
| 容量ヒント | Capacity Hint | ルートの物理容量見積もり（人/分） |
| 方向転換率 | Turn Ratio | 出口配分<br>原則内部導出（観測は任意） |

## 危険の概念

| 語 | 英語 | 内容 |
|---|---|---|
| 危険箇所 | Risk Location | パンクまたは高停滞のポイント／ルート |
| パンク | Puncture | 容量ヒント持ちスカラールートが容量到達 |
| 高停滞 | High Stagnation | 停滞量が履歴パーセンタイル以上かつ上昇幅一定以上 |
| 危険フラグ | Danger Flag | スタッフ／オーナーの手動危険宣言 |

危険度（Risk Level）は Flow Control 専用であり、共有カーネルには含めない。

## 不変条件

- スコア比較は同一イベント内の同一ポイント／ルートの過去スコアに対してのみ
- 流量と占有量変化は正準単位（人/分）に正規化し、人数スコアと停滞量スコアは人数（人）のまま受け渡す
- グラフは Flow Control が保持せず、外部が毎回渡す（正本＝グラフ編集／受け渡し＝観測）
- ゲートはポイントの特化／行列は停滞量スコアの局所ビュー
- カーネルにはゲートと行列を持ち込まない
- 共有カーネル自体は固有のドメインイベントを持たない
